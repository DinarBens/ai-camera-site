# ИИ-камера — контроль отгрузки

Одностраничный сайт: `index.html` и картинки в `img/`. Сборка не нужна.

## Номер WhatsApp

В конце `index.html` впишите номер в строку `const WHATSAPP = "";` — только цифры с кодом страны, например `77011234567`. Все кнопки «Оставить заявку» откроют чат с этим номером и готовым текстом.

## Публикация на GitHub Pages

Settings → Pages → Source: Deploy from a branch → Branch: `main`, папка `/ (root)`.

Кадры — с тестовой погрузки, лица работников размыты.
